# MAMORU (護る・見守る)
### 在宅介護・施設向け「IoTセンサー連携＆時系列AIバイタル監視Webアプリ」プロトタイプ

元理学療法士（PT）の臨床知見を取り入れた、介護施設・在宅ケア向けのリアルタイムバイタル監視＆時系列AI予兆検知プラットフォームです。
単なる数値の羅列ではなく、ケアスタッフやリハビリ職が直感的に急変・リスクを把握できるUI/UXと、そのまま介護記録・日誌に転記できるAIアセスメント生成機能を備えています。

---

## 🌟 主な機能

### 1. リアルタイム・バイタル＆センサーダッシュボード
- **バイタル＆離床一覧監視**: 各利用者の心拍数、呼吸数、推定体温、離床センサー状態（在床 / 端座位 / 離床中 / 体動停止）をカード形式でライブ表示。
- **3段階トリアージ**: 緑（安定）、黄（要観察・微熱/脱水兆候）、赤（警告・頻脈/無呼吸/離床）の直感的カラーとパルスアニメーション。
- **緊急アラートバナー**: 心拍数120以上、10秒以上の無呼吸や離床検知時に視覚的アラートをトップに発報。
- **デモ用センサーシミュレーター**: 「夜間頻脈」「離床転倒リスク」「無呼吸停止」などのシナリオをワンクリックで発火可能。

### 2. 時系列データグラフ可視化（Recharts）
- **過去24時間〜7日間の推移**: 心拍数、呼吸数、活動量/体動指数の複合グラフ表示。
- **ベースライン乖離の可視化**: 利用者個別の平常安静時心拍数ライン（ReferenceLine）や警告閾値（120bpm）を重ねて表示。
- **イベント注記ツールチップ**: 夜間帯（深夜2時〜4時）の心拍上昇や離床イベントを詳細確認。

### 3. 時系列AIアセスメント（予兆検知）生成エンジン
- **フォーマット化された臨床分析出力**:
  1. **【リスクレベル】**: 低・中・高
  2. **【変化の分析】**: 平常安静時ベースラインとの乖離、深夜帯の微細な変化を検出
  3. **【推測される状態・対策】**: うっ血性心不全代償性頻脈、脱水、感染徴候、転倒リスク等に対するPT・ケア指示
  4. **【介護記録用テキスト】**: そのまま電子カルテや介護日誌に転載できる文面
- **ワンクリック日誌コピー機能**: クリップボードへ即座にコピーし、業務効率を劇的に改善。
- **ハイブリッドエンジン**: Gemini API連携 ＋ APIキー不要で動くスマート臨床推論フォールバックを完備。

## 🛠 技術スタック
- **フロントエンド**: Next.js 15 (App Router), React 19, TypeScript
- **スタイリング**: Tailwind CSS (医療テックテーマ)
- **グラフライブラリ**: Recharts
- **アイコン**: Lucide React
- **AIエンジン**: Google Gemini API / 臨床ルールベースハイブリッド推論
- **ホスティング**: Vercel想定

## 🚀 ローカル起動方法

```bash
# 依存関係インストール
npm install

# 開発サーバー起動
npm run dev

# または本番ビルド & 起動
npm run build
npm run start
```

ブラウザで `http://localhost:3000` を開きます。
